# Privacy Policy

This app is a personal tool. It connects the owner's own Google account (Calendar, Tasks, Gmail, Drive, Docs, Sheets) to the owner's own AI assistant on the owner's own computer.

The app runs only on the owner's computer. There is no server and no database.

Google data is read or changed only when the owner asks the assistant to do so.

Data is not collected, stored, sold or shared with anyone. It is not used for advertising or to train AI models.

The login token is stored only on the owner's computer.

Access can be removed at any time at https://myaccount.google.com/permissions

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
